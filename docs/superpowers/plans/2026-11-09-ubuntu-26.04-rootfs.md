# Ubuntu 26.04 rootfs Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Ubuntu 26.04 rootfs builds for amd64, arm64, arm32, and riscv64, with QEMU boot tests, CI matrix coverage, and documentation.

**Architecture:** Clone the existing `type-ubuntu24.04` generator as `type-ubuntu26.04`, changing only the Docker base tag to `ubuntu:26.04`. Extend the shared architecture helper and the multiarch test/CI harness to cover both 24.04 and 26.04.

**Tech Stack:** Bash, Docker, qemu-user/binfmt, qemu-system, GitHub Actions.

## Global Constraints

- Canonical architectures: `amd64`, `arm64`, `arm32`, `riscv64`.
- Ubuntu types accepting all architectures: `ubuntu22.04`, `ubuntu24.04`, `ubuntu26.04`.
- Default architecture is `amd64`; default output `rootfs_<arch>.ext4` for every architecture.
- Ubuntu 26.04 uses the exact same package list and inside-container configuration as 24.04.
- Kernel version stays 6.1.22; no kernel changes.
- Do not create git commits unless the user explicitly asks.

### Task 1: Create the ubuntu26.04 rootfs type

**Files:**
- Create: `type-ubuntu26.04/init-rootfs.sh`
- Create: `type-ubuntu26.04/run-container.sh`
- Create: `type-ubuntu26.04/inside-container.sh`

**Interfaces:**
- Consumes: exported env vars `SPARSE`, `DOCKER_PLATFORM`, `SERIAL_CONSOLE` from `build-rootfs.sh`.
- Produces: the executable scripts that `build-rootfs.sh` invokes as
  `type-ubuntu26.04/init-rootfs.sh <image>` and
  `type-ubuntu26.04/run-container.sh <image>`.

- [ ] **Step 1: Create `type-ubuntu26.04/init-rootfs.sh`**

```bash
#!/bin/bash

# Create the rootfs and format it
if [[ "$SPARSE" -eq 1 ]]; then
    dd if=/dev/zero of="$1" bs=1 count=0 seek=2048M > /dev/null
else
    dd if=/dev/zero of="$1" bs=1M count=2048 > /dev/null
fi
yes | mkfs.ext4 "$1" > /dev/null
```

- [ ] **Step 2: Create `type-ubuntu26.04/run-container.sh`**

```bash
#!/bin/bash
set -e
SCRIPT_DIR="$( cd "$(dirname "$0")" >/dev/null 2>&1 ; pwd -P )"

# Launch the target-architecture container
cont_id=$(docker run -td --rm --privileged --platform "$DOCKER_PLATFORM" -v "$1:/rootfs.ext4" ubuntu:26.04)

# Install systemd
docker exec -t "$cont_id" /bin/bash -c "apt-get update && DEBIAN_FRONTEND='noninteractive' apt-get install -y systemd"

# Run the payload in the already-running container. Services are enabled offline
# so this also works under qemu-user emulation.
set +e
docker exec -t -e SERIAL_CONSOLE="$SERIAL_CONSOLE" "$cont_id" /bin/sh -c "`cat "$SCRIPT_DIR/inside-container.sh"`"

rval=$?
set -e

docker stop "$cont_id"

if [[ "$rval" != 0 ]]; then
    echo "Error running the payload"
    exit 1
fi
```

- [ ] **Step 3: Create `type-ubuntu26.04/inside-container.sh`**

```sh
#!/bin/sh
set -e
SERIAL_CONSOLE="${SERIAL_CONSOLE:-ttyS0}"

### Customize me!
DEBIAN_FRONTEND="noninteractive" apt-get install -y \
      git \
      gcc \
      libc6-dev \
      vim \
      sudo \
      ethtool \
      iputils-ping \
      net-tools \
      openssh-server \
      openssh-client \
      udhcpc \
      apt \
      ca-certificates \
      iproute2 \
      strace \
      qt6-base-dev \
      g++ \
      make \
      pkg-config \
      python3-tk \
      kmod \
      xserver-xorg-core \
      xserver-xorg-input-libinput \
      xinit \
      xauth \
      x11-utils \
      libxcb-cursor0 \
      openbox \
      fonts-dejavu-core \
      libgl1-mesa-dri

# Enable SSH
echo "PermitRootLogin yes" >> /etc/ssh/sshd_config
systemctl enable ssh

# Set password
echo "root:root" | chpasswd

# QEMU user-mode networking: let udhcpc own resolv.conf
systemctl disable systemd-resolved 2>/dev/null || true
systemctl mask systemd-resolved.service 2>/dev/null || true
rm -f /sbin/resolvconf

cat > /etc/systemd/system/udhcpc.service <<'EOF'
[Unit]
Description=udhcpc DHCP client on eth0
After=network.target
ConditionPathExists=/sys/class/net/eth0

[Service]
Type=simple
ExecStart=/usr/sbin/udhcpc -f -i eth0 -R -s /etc/udhcpc/default.script
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl enable udhcpc.service

# Enable the serial console; use serial-getty@ and drop the plain getty@
# symlink so the auto-generated serial unit does not fight with it.
systemctl enable "serial-getty@${SERIAL_CONSOLE}"
systemctl disable "getty@${SERIAL_CONSOLE}" 2>/dev/null || true

# Mount the host linux-app share on first access
mkdir -p /mnt/linux-app
if ! grep -q ' /mnt/linux-app ' /etc/fstab 2>/dev/null; then
    echo 'linuxapp /mnt/linux-app 9p trans=virtio,version=9p2000.L,nofail,x-systemd.automount 0 0' >> /etc/fstab
fi

# Then, copy the newly configured system to the rootfs image:
mkdir /my-rootfs
mount /rootfs.ext4 /my-rootfs

for d in bin etc lib lib64 root run sbin usr var; do
    if [ -e "/$d" ]; then
        cp -a "/$d" /my-rootfs/
    fi
done
for dir in dev proc run sys var tmp; do mkdir -p "/my-rootfs/${dir}"; done
umount /my-rootfs

# All done, exit docker shell
exit
```

```bash
#!/bin/bash
set -e

SCRIPT_DIR="$( cd "$(dirname "$0")" >/dev/null 2>&1 ; pwd -P )"
cd "$SCRIPT_DIR/.."

if [[ $EUID -ne 0 ]]; then
    echo "This script must be run as root"
    exit 1
fi

TYPE="${1:-ubuntu24.04}"

for arch in arm64 arm32 riscv64; do
    echo "=== Building $TYPE for $arch ==="
    ./build-rootfs.sh "$TYPE" --arch "$arch"
    ./tests/qemu-test.sh "$(realpath "rootfs_$arch.ext4")" "$arch"
    rm -f "rootfs_${TYPE}_$arch.ext4"
    mv "rootfs_$arch.ext4" "rootfs_${TYPE}_$arch.ext4"
done

echo "All multiarch tests passed"
```

### Task 4: Run the multiarch CI matrix over 24.04 and 26.04

**Files:**
- Modify: `.github/workflows/multiarch.yml`

**Interfaces:**
- Consumes: `tests/test-multiarch.sh <type>` and `tests/test-tools.sh <image> <arch>`.
- Produces: one CI matrix job per Ubuntu version.

- [ ] **Step 1: Replace the workflow with the matrix version**

```yaml
name: Multiarch CI

on:
  push:
    branches: [ master ]
  pull_request:
    branches: [ master ]
  workflow_dispatch:

jobs:
  multiarch:
    runs-on: ubuntu-latest
    timeout-minutes: 240
    strategy:
      fail-fast: false
      matrix:
        type: [ubuntu24.04, ubuntu26.04]

    steps:
      - uses: actions/checkout@v4

      - name: Install prerequisites
        run: |
          sudo apt-get update
          sudo apt-get install -y docker.io qemu-system-arm qemu-system-misc qemu-user-static expect

      - name: Register binfmt handlers
        run: docker run --privileged --rm tonistiigi/binfmt --install arm,arm64,riscv64

      - name: Build and test multiarch ${{ matrix.type }} images
        run: sudo ./tests/test-multiarch.sh ${{ matrix.type }}

      - name: Test ${{ matrix.type }} arm64 tools and networking
        run: sudo ./tests/test-tools.sh rootfs_${{ matrix.type }}_arm64.ext4 arm64
```
